## 2. 애니메이션을 넣었을 때 충돌 `[판단]`

| 묶음 | 넣을 만한 애니메이션 | 충돌 지점 | 위험 |
| --- | --- | --- | --- |
| A 상태 전환 | 문 열림·닫힘, 셔터 말림, 해치 젖힘, 레이저 켜짐 | ① 판정은 Shift를 누르는 **순간** 바뀌는데 그림이 늦게 바뀌면 "열린 것처럼 보이는데 막힘/반대"가 생김 ② 판정을 애니메이션 끝까지 미루면 **타이밍 퍼즐의 기준과 추적도 비용이 바뀜**(03-02 안 A·B 계산이 달라짐) ③ 짧게 누르기(탭)에서 반쯤 열린 그림이 깜빡임 | **높음** |
| B 위치 이동 | 다리·간판이 미끄러짐 | 미끄러지는 동안 인물이 건널 수 있는지(판정 위치 vs 그림 위치). 간격 0.1초 이하면 체감 차이 작음 | 중간 |
| A+B 엘리베이터 | 칸이 위아래로 이동 | 이동 시간을 보여 주면 **인물이 층을 옮기는 데 시간이 생김** → 지금 규칙(즉시 도착)과 레벨 타이밍이 모두 바뀜 | **높음** |
| C 통과 표지 | 단말 화면 깜빡임, 중계기 불빛, 출구 표지 점멸 | 목표를 잘 보이게 해 줌(좋음). 단, 같은 깜빡임을 장식(F)에도 쓰면 **조작할 수 있는 것처럼 보임** | 중간 |
| D 인물 | 걷기 4프레임, 기다림(해커 신호 기다리는 동작), 돌아섬, 해치로 떨어짐 | 걷기 프레임과 이동 속도(48px/초)가 안 맞으면 발이 미끄러져 보임. 판정은 몸 중심 x라 충돌 없음. 기다림 동작은 "막혀 있음"을 알려 줘 **오히려 이해를 도움** | 낮음 |
| E 표시 | 조준틀 맥박, 설계도 겹침 글리치 흔들림 | 조준틀이 오브젝트 그림을 가리면 상태를 읽기 어려움. 글리치 흔들림은 픽셀이 정수 위치를 벗어나면 도트 규칙(D-035) 위반 | 중간 |
| F 장식·조명 | 서버 불빛, 모니터 깜빡임 | **조작 대상으로 오인**(가짜 신호). 배경 이펙트 금지(D-040)와 경계 | 중간 |

## 3. 규칙 제안 `[제안]`

### 3-1. 판정과 그림

1. **판정은 즉시, 그림은 따라간다.** 애니메이션이 규칙 판정을 늦추지 않는다(타이밍·추적도 계산 보호).
2. 상태 전환 그림은 **2프레임 이하(약 0.07초)**로 끝낸다. 짧게 누르기에도 "바뀐 상태"가 바로 보여야 한다.
3. Shift를 누르는 동안의 설계도 겹침(L6)은 **목표 상태**를 보여 준다. 전환 애니메이션 위에 겹쳐 결과를 먼저 알려 준다.
4. 엘리베이터는 1차 범위에서 **이동 애니메이션 없음**(즉시 도착 유지). 도착 쪽에서 문이 열리는 2프레임만.
5. 위치 이동형은 **판정 위치 = 목표 단계**, 그림은 0.1초 안에 따라감.

### 3-2. 반복 애니메이션(가만히 있을 때)

6. 반복 애니메이션은 **C 통과 표지형과 인물에만** 쓴다(목표·인물 강조). 장식(F)과 조명(L3)은 반복 애니메이션을 쓰지 않는다 → 가짜 신호 방지, D-040 유지.
7. 조준할 수 있는 오브젝트(A·B)는 반복 애니메이션 대신 **조준 시 테두리**로 알린다.

### 3-3. 공통 규격

| 항목 | 규격 |
| --- | --- |
| 기준점 | 바닥 오브젝트 = 아래 가운데가 바닥선 / 벽걸이 = 지정 좌표(layout.json) / 섹터 전체 = 섹터 왼쪽 위 |
| 프레임 | **30 FPS 기준(D-077)**. 전환 2프레임(≈0.07초), 인물 걷기 한 주기 16프레임(0.53초)·기다림 24·떨어짐 10. 천천히 바뀌는 반복은 프레임을 늘리지 않고 manifest `holds`(프레임별 유지 틱)로 표현 |
| 이름 | `<종류>_<상태>_<프레임 번호>.png` (예: `door_open_0`, `door_open_1`) |
| 외곽선 | 모든 상태·프레임에서 바깥 외곽선 1px `K` 유지(열린 상태 포함) |
| 설계도 그림 | 조작할 수 있는 오브젝트는 **두 상태 모두**의 설계도 그림을 가진다(`bp_<종류>_<상태>`) |
| 크기 | 같은 오브젝트의 모든 상태·프레임은 같은 캔버스 크기 |
