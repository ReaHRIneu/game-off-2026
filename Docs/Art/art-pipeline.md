- **작성일**: 2026-11-17
- **버전**: v0.1.0
- **담당 AI**: Claude Code(설계·제작)
- **연관 문서**: [컨셉](../Planning/01-01-concept.md) v0.12.0, [시스템 기획](../Planning/02-01-system-design.md) v0.1.0, [크레딧·AI 기록](../Event/credits-and-ai-log.md)

> 표기: `D-ID`는 사용자 결정, `[제안]`은 에이전트 제안(미확정)이다. 이 문서의 스타일·크기·팔레트는 모두 `[제안]`이며, 사용자가 정하면 결정 기록부에 남긴다.

## 1. 제작 방식

이 게임의 그림은 **코드로 그린다.** Claude Code에는 이미지 생성 기능이 없어서, 그림을 그리는 Python 코드(레시피)를 작성해 PNG를 만든다.

| 대상 | 방식 | 위치 |
| --- | --- | --- |
| 타일·아이콘·UI 조각 | Python(Pillow) 레시피 → PNG | `Art/recipes/*.py` → `Art/Export/` |
| 층 어긋남·글리치·스캔라인 같은 화면 효과 | Unity 셰이더(Shader Graph 또는 HLSL) | `Unity/Assets/_Project/Shaders/` |
| 글꼴 | OFL 등 재배포 가능한 무료 글꼴만 | 라이선스를 크레딧 기록에 남김 |

- 이 게임의 아트 방향(청사진 — D-019, 감시 화면, 프로그램 창)은 선과 도형 위주라 코드 제작과 잘 맞는다.
- 외부 유료 이미지 생성 API는 사용자가 승인한 경우에만 쓴다. **API 키는 저장소에 기록하지 않는다**(AGENTS.md 보안 규칙).
- 다른 저장소의 개인용 도구 코드를 가져오지 않는다. 이 저장소의 `tools/art/`는 이 프로젝트용으로 새로 작성했다.

## 2. 실행 방법

```bash
python -I tools/art/build_art.py            # 모든 레시피 실행
python -I tools/art/build_art.py tiles_mvp1 # 특정 레시피만
```

- 공용 함수: `tools/art/artkit.py` (팔레트, 격자, 화살표, 빛 번짐, 저장, 미리보기 시트)
- 출력: `Art/Export/<종류>/<이름>.png`, 목록은 `Art/Export/manifest.json`
- 검수용 미리보기: `Art/Export/preview/*.png`
- 필요 환경: Python 3.12, Pillow(설치 확인함). 추가 설치 없음.

## 3. Unity 반입

- 확정된 PNG만 `Unity/Assets/_Project/Art/`로 복사한다. 시안은 반입하지 않는다.
- 임포트 설정 `[제안]`: Sprite(2D and UI), Pixels Per Unit = 64, Filter Mode = Point(선 선명도 유지), Compression = None.
- 레시피를 다시 실행해 그림이 바뀌면 같은 파일 이름으로 다시 복사한다(.meta 유지).

## 4. 스타일 기준 `[제안]`

| 항목 | 제안값 |
| --- | --- |
| 타일 크기 | 64×64 px, PPU 64 |
| 현실 층 | 어두운 회청색 평면 도형, 얇은 윤곽선(감시 화면 느낌) |
| 설계도 층 | 청사진 파란 바탕(반투명) + 16px 격자 + 밝은 하늘색 선, 약한 빛 번짐. 현실 위에 **겹쳐** 보여서 지우기처럼 보이지 않음(D-015) |
| 강조색 | 경고·추적도 = 분홍빨강, 완료·통과 = 민트 |
| UI | 단색 프로그램 창 틀, 고정폭 글꼴. 실제 OS 디자인 모방 금지 |

팔레트 값은 `tools/art/artkit.py`의 `PALETTE`가 정본이다.

## 5. 제작 기록 규칙

- 레시피를 만들거나 바꾸면 `Docs/Event/credits-and-ai-log.md`의 AI 사용 표에 한 줄 남긴다(도구: Claude Code, 방식: 코드 생성).
- 시안과 확정본을 구분한다. `manifest.json`의 `status`가 `시안`이면 사용자 확정 전이다.
- 실제로 실행해 PNG를 확인한 것만 완료로 보고한다.
