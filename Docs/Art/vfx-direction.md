## 1. 연출의 역할 `[제안]`

연출은 플레이어에게 아래 4가지를 알려 줄 때만 쓴다.

1. **내 입력이 먹혔다**(조준·Shift)
2. **무엇이 바뀌었다**(장치 상태·위치)
3. **위험이 커진다**(추적도·카운트다운)
4. **결과가 났다**(미션 완료·가두기·실패·클리어)

## 2. 연출 목록 `[제안]`

우선순위: **P1** = 제출 전 꼭, **P2** = 여유가 있으면, **P3** = 2차 이후.

## 3. 연출 규칙 `[제안]`

| 항목 | 규칙 |
| --- | --- |
| 길이 | 입력·상태 피드백 0.1초 이하, 결과 연출 0.5초 이하. 입력을 막지 않음 |
| 동시에 | 같은 위치의 연출은 1개만(새 연출이 이전 연출을 끝냄) |
| 깜빡임 | 초당 3회 이하(빛에 민감한 사람 배려). 화면 전체 깜빡임은 쓰지 않음 |
| 흔들림 | 화면 흔들림 대신 **줄 어긋남 글리치**(SHIFT 주제). 흔들림 폭은 정수 픽셀 |
| 색 | 공유 팔레트만. 위험 = 빨강(R), 성공 = 민트(G), 설계도 = 청사진 파랑(B·b·C) |
| 레이어 | 연출은 해당 오브젝트 레이어 위(L4·L5 바로 위) 또는 L8(표시). 배경 레이어(L0~L3)에는 넣지 않음(D-040) |
| 설정 | 연출 길이·세기는 설정 값으로 모아 조정 가능하게 |

## 4. 만드는 방법 `[제안]`

| 종류 | 도구 | 예 |
| --- | --- | --- |
| 프레임 애니메이션 | `tools/art/anim.py` 시트 + manifest | 문·해치·레이저 전환, 인물 |
| 코드 연출 | 그리기 코드에서 위치·오프셋·색 바꾸기(새 그림 필요 없음) | 조준틀 미끄러짐, 설계도 어긋남 진입, 줄 어긋남 글리치, 결과 창 올라옴 |
| 작은 아이콘 | 레시피로 128px 규격 아이콘 | 체크 튀어 오름, `TRAPPED` 도장 |
| 셰이더 | 1차에서는 쓰지 않음 — 코드 연출로 충분, W-009 GPU 전환 뒤 검토 | 청사진 격자 흐름 |

## 5. 작업 순서·일정 `[제안]`

1. W-009(GPU 렌더링) 완료 — 연출의 바탕
2. **P1 코드 연출 묶음(W-010)**: 조준 미끄러짐, Shift 진입·이탈 어긋남, 추적도 깜빡임·테두리 띠, 카운트다운 숫자, 게임오버 줄 글리치, 실패 지점 깜빡임, 결과 창 올라옴·별 찍힘
3. **P1 프레임 연출**: 문·셔터·해치·레이저 전환 본그림(128px), 체크 아이콘·`TRAPPED` 도장
4. P2는 남은 일정 보고 선택
