## 목표

테스트 의뢰 1개를 처음부터 끝까지 플레이할 수 있는 MVP-1을 Unity에 구현한다. 기획 내용은 근거 문서를 따르고, 이 지시서는 구현 범위와 임시값만 정한다.

## 범위

- Unity 프로젝트: `Unity/` (6000.6.0f1, Universal 2D)
- 새 파일 위치: `Unity/Assets/_Project/` 아래 (`Scripts/`, `Scenes/`, `Data/` 등). 템플릿의 `Assets/Welcome/`·`SampleScene`은 건드리지 않아도 된다.
- 메인 씬 1개를 만들고 Build Settings의 첫 씬으로 등록한다.

## 구현 항목 (근거: 02-01 시스템 1~6)

1. **입력·조준** (2026-11-17 변경 — D-036~D-038, 02-01 v0.2.0 시스템 1 참조): **마우스 입력 없음.** 방향키 단독 = 누른 방향의 **다음 조작 가능한 칸(현실≠설계도인 칸)으로 조준 점프**, 후보 선택은 `진행 축 거리 + 2×옆 축 거리` 최소, 후보 없으면 유지. 메뉴는 방향키 선택 + Enter 결정. 첫 화면 "Press Enter". **왼쪽 Shift만** 인식(`Keyboard.current.leftShiftKey` 등 물리 키 기준, 오른쪽 Shift 무시). Shift를 누른 동안 방향키는 무시. `ESC` 일시정지(계속 / 다시 시작, 방향키 + Enter). 포커스를 잃으면 일시정지.
2. **층 어긋남**: 각 칸에 현실·설계도 두 상태. 왼쪽 Shift를 누르는 동안 조준한 칸의 유효 상태 = 설계도 상태. 설계도 상태는 파란 외곽선 + 반투명으로 겹쳐 표시(칸이 사라진 것처럼 보이지 않게).
3. **대상 이동**: 의뢰 대상 1명. 시작 대기 3초 후 0.5초마다 진행 방향으로 1칸. 다음 칸의 **그 순간 유효 상태**가 통행 불가면 제자리 대기. 방향 칸에 **들어선 순간의 유효 상태**로 방향 변경.
4. **추적도**: 최대 100, 왼쪽 Shift를 누르는 동안 초당 20 증가. 떼도 감소 없음. 미션 완료 시 −30, 중계기 통과 시 −40(1회). 100 도달 시 카운트다운 5초. 그 사이 100 미만이 되면 해제. 0초가 되면 게임오버 화면 → 다시 시작.
5. **의뢰·미션·성급**: 최종 미션 = 대상이 출구 도달 → 즉시 의뢰 종료. 나머지 미션 = 체크 지점 A·B 통과. 별: ★ 최종만 / ★★ + 나머지 1개 이상 / ★★★ 전부. 결과 화면에 별 표시 + 다시 시작. 다시 시작은 **전부 초기화**(추적도·미션·대상 위치·카운트다운).
6. **화면**: 단순 도형으로 프로그램 창 틀, 격자, 미션 목록(체크), 추적도 게이지, 카운트다운 숫자, 명령 기록 줄(예: `> LShift`, `> →`). UI 문자는 영문(해외 평가자 대상). 실제 OS 디자인을 흉내 내지 않는다.

- **임시값은 한곳에 모은다**: 추적도·이동 간격·카운트다운·감소량 등은 설정 에셋(ScriptableObject) 하나에 두어 밸런스 기획 때 바꾸기 쉽게 한다.
- **의뢰 데이터**: 두 층의 문자열 격자를 담은 데이터 에셋으로 정의한다(코드에 하드코딩하지 않음).

## 테스트 의뢰 `[임시]` — 레벨 기획 전 기능 확인용

범례: `#` 벽, `.` 바닥, `S` 시작(대상은 오른쪽을 봄, 바닥), `D` 닫힌 문, `O` 열린 문, `> < ^ v` 방향 칸, `E` 출구, `A`·`B` 체크 지점, `R` 중계기

현실 층:

```
############
#S.>....D.E#
###.######.#
#..>A.D.BR^#
############
```

설계도 층(현실과 다른 칸만: (3,1) `>`→`v`, (8,1) `D`→`O`, (6,3) `D`→`O`):

```
############
#S.v....O.E#
###.######.#
#..>A.O.BR^#
############
```

- 좌표는 (x, y), 왼쪽 위가 (0,0).
- 기본 경로: 윗줄 문(8,1)을 설계도로 열고 출구 → ★
- 우회 경로: (3,1)에서 설계도로 아래로 꺾고 → A → 문(6,3) 열기 → B → 중계기 → 위로 → 출구 → ★★★
