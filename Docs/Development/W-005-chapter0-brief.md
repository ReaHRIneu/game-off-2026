### 3. 튜토리얼 동작(챕터 0 전용, 레벨 데이터의 `tutorial` 표시로 켜고 끔) `[제안]`

| 항목 | 동작 |
| --- | --- |
| 단계 안내 | **장면 패널 위쪽 안쪽**에 안내 상자(`ui/panel` 9-slice + 글자 + 키 배지)를 띄운다. **LOG 탭 대화가 아니다**(D-045 유지). 단계 조건·문구는 03-01 §1-1·§1-2 표. 키 배지: `SHIFT`는 배지 그림 함수로 글자 `SHIFT`, `→`는 글자 `→` |

### 4. 바탕화면 챕터 폴더 `[제안]` — 02-03 §5-3

- 바탕화면 첫 화면 = 챕터 폴더 아이콘 세로 배치: `CH0_SANDBOX`(열림, `ui/icon_folder_open`), `CH1_???`, `CH2_???`(잠김, `ui/icon_folder_locked`)
- 폴더에서 Enter → 그 챕터의 의뢰 아이콘 목록(현재 아이콘 화면과 같음, 이름 `REQ_0-1`, `REQ_0-2`). 위쪽에 경로 글자 `/CH0_SANDBOX/`
- 의뢰 목록에서 ESC → 폴더 화면. 폴더 화면에서 ESC → 메인(기존)
- 잠긴 폴더 Enter → 상세 패널에 `LOCKED` 표시(기존 잠긴 의뢰와 같은 방식)
- 챕터 열림 규칙: 앞 챕터 의뢰가 모두 ★1 이상. 챕터 1·2는 의뢰가 없으므로 이번에는 항상 잠김
- 의뢰 잠금(챕터 안): 앞 의뢰 ★1 이상(기존 규칙)
- 결과 Enter → 그 챕터의 의뢰 목록으로 돌아감
