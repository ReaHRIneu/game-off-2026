## 규칙 요점

- 주제 **SHIFT**, 해석 자유.
- **공개 GitHub 저장소 필수**. 라이선스 자유, 커밋 기록 필수 아님.
- **itch.io 잼 페이지에서 따로 제출**해야 참가 처리됨(push만으로는 안 됨).
- 엔진·플랫폼·팀 인원 제한 없음. 여러 작품 제출 가능.
- 기존 템플릿·라이브러리·에셋 사용 가능. 단 대부분은 잼 기간에 제작. 잼 전 작업은 투명하게 밝힘.
- **AI 사용 허용, 제출 시 공개 필요**. 사용 자체로 감점되지 않음.
- 유료 에셋은 저장소에서 빼고 README에 필요 에셋을 적을 수 있음.
- 미완성 프로토타입 제출 가능. 옛 게임을 조금 고친 제출은 금지.
- 투표 기간에는 치명적 버그만 수정하고 변경 내용을 기록.
- 무료 배포 권장.
