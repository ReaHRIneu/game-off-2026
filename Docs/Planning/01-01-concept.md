## 한 줄 소개 (로그라인)

> SF 디스토피아의 뒷세계 해커가 되어, 가상 프로그램 창 속 현실 장면을 보며 왼쪽 Shift를 누르는 동안 조준한 공간의 설계도 층을 어긋나게 해 원격으로 의뢰를 해결하는 단축키 퍼즐 게임. `[제안 — 대외용 한 줄 소개 문장은 사용자가 나중에 정함]`

## 기획 배경

- **목적**: GitHub Game Off 2026(주제 SHIFT) 1인 참가. 기획 역량을 보여 줄 포트폴리오용 작품 — D-001
- **주제 해석**: Shift 키 조작(D-005), 공간이 어긋나는 왜곡(D-015), 해커가 다루는 데이터 층(D-017)이 모두 SHIFT로 이어진다.

## 핵심 재미 (Core Fun)

> SF 디스토피아 세계에서 활동하는 뒷세계 해커가 되어 여러 가지 의뢰를 맡으며, 간단한 조작키 조합으로 주어진 상황을 퍼즐처럼 풀어 간다. — D-013

플레이 검증(결정·검증 절차 2-1)의 기준 문장이다.

## 핵심 컨텐츠 / 파생 컨텐츠

- **핵심 컨텐츠**: 의뢰(= 스테이지) — D-013, D-023. 의뢰 1건 = 화면 속 현실 장면 1개 `[제안]`
- **파생 컨텐츠**: 특수 스테이지(종료 조건이 다른 의뢰) — D-027. 종류는 `→ 레벨 기획`

## 핵심 시스템 (개요)

상세 규칙은 2차 기획(`02-01-system-design.md`)에서 다룬다.

### 1. 조작

- 프로그램·Windows 단축키처럼 `Shift + 키` 형식으로 조작한다. 초반에는 Shift만 쓰고, 진행할수록 조합이 늘어난다 — D-005
- 인게임 조작은 Shift·영문·숫자·방향키 조합만 쓴다. 일시정지(ESC) 같은 시스템 조작키는 예외다 — D-006
- Shift는 **왼쪽 Shift만** 쓴다 — D-012
- 조준: 방향키로 조준틀을 옮기는 커서형 `[제안]`
- 조합 키(`Shift + 방향키·숫자·영문`)의 의미와 등장 순서 `→ 레벨 기획` — D-032

### 2. 층 어긋남 (공간 왜곡)

- Shift를 누르면 조준한 공간이 왜곡되고, 이것으로 현실을 조작한다 — D-007
- 모든 왜곡은 위치나 상태가 **어긋나는 것**이다. 지우거나 새로 만드는 왜곡은 쓰지 않는다 — D-015
- 왼쪽 Shift 단독: 누르는 동안 조준한 칸에 겹쳐 있던 **설계도 층**(도시 관리 시스템의 데이터 층)이 드러나고, 떼면 원래대로 돌아온다 — D-010, D-016, D-017
- 층은 **현실 + 설계도 2개로 고정** — D-018
- 설계도 층은 **청사진**으로 표현한다 — D-019. 세부(파란 선·격자, 글리치로 어긋나 겹침)는 `[제안]`

### 3. 추적도

- **증가**: Shift를 누르고 있는 동안 오른다 — D-011, D-020
- **감소**: 손을 떼도 줄지 않는다. 미션·조건 달성이나 특정 트리거 작동으로만 줄어든다 — D-021
- **최대치**: 도달하면 **카운트다운**(패널티)에 들어간다. 끝나기 전까지 추적도를 낮추지 못하면 **게임오버** — D-022, D-025
- 증가 속도·감소량·카운트다운 길이 `→ 밸런스 기획` — D-020, D-033

### 4. 의뢰·미션·성급

- **의뢰 = 스테이지** — D-023
- 의뢰 안에 **미션(조건)이 여러 개** 있다. 일부 특수 스테이지를 빼면 **최종 미션을 완료하는 시점에 의뢰가 끝난다** — D-024, D-027
- 클리어 성급은 **별 3개**이고, 완료한 미션 개수로 정한다 — D-026, D-028

| 별 | 조건 — D-030 |
| --- | --- |
| ★ | 최종 미션 완료 |
| ★★ | 최종 미션 + 나머지 미션 절반 이상 완료 |
| ★★★ | 모든 미션 완료 |

- 게임오버 후 재시작이나 실패 후 다시 시작은 **해당 의뢰의 처음부터** 진행한다. 추적도와 미션 진행을 모두 처음 상태로 되돌린다 — D-029, D-031

### 5. 실시간 진행

- 화면 속 현실(사람·차량 등)은 실시간으로 움직인다 — D-009

## 핵심 루프 (Core Loop)

`[제안]` — 위 결정을 순서로 묶은 것

1. 의뢰 브리핑에서 최종 미션과 나머지 미션을 확인한다.
2. 화면 속 현실 장면을 관찰한다.
3. 조준하고 왼쪽 Shift를 눌러 설계도 층을 드러낸다. 누르는 동안 추적도가 오른다.
4. 미션을 달성하고 트리거를 작동해 추적도를 낮춘다.
5. 별을 더 얻기 위해 나머지 미션을 할지, 최종 미션으로 끝낼지 판단한다.
6. 최종 미션을 완료하면 별 성급을 받고 다음 의뢰로 넘어간다.

## 경쟁작 / 유사 게임 분석 & 차별점 (포지셔닝)

2026-11-17 웹 검색 결과 기준. 직접 플레이하지 않았다.

| 게임 | 유사한 점 | 다른 점 |
| --- | --- | --- |
| Shift 시리즈(Armor Games, 2008~) | Shift 키로 방 전체를 뒤집어 흑백 반전 | 우리는 **조준한 칸만** 설계도 층으로 어긋나게 하고, 조합 키가 늘어난다 |
| CTRL+SHIFT(itch.io) | 버튼으로 2D/3D 시점 전환 | 시점 전환이 아니라 층 어긋남 |
| Losing Control, CTRL_, Ctrl(calicospartan) 등 GMTK 2020 출품작 | 단축키(`Ctrl+C/V/X`)를 퍼즐 조작으로 사용 | Ctrl 계열을 쓰지 않음. Shift 조합만 사용 |
| Press Any Key to Continue(GMTK 2025) | 키의 기능을 하나씩 알아 가는 구조 | (상세 미확인) |

**차별점** `[제안]`: Shift 하나에서 시작해 조합을 배우는 진행 + 해커가 현실과 설계도 층의 틈을 이용하는 설정 + 추적도라는 시간 자원.

## 세계관 / 스토리 개요

- 세계는 **SF 디스토피아**이고, 플레이어는 그 세계의 **뒷세계 해커**다 — D-008, D-014
- 해커는 여러 가지 **의뢰**를 맡아 해결한다 — D-014
- 도시에는 관리 시스템의 **설계도 층**(데이터 층)이 현실과 겹쳐 있다. 해커는 이 틈을 이용한다 — D-017
- 게임 화면은 **가상의 프로그램 창**이다. 창 속에 현실 장면이 보이고, 플레이어는 원격으로 의뢰를 수행한다 — D-008
- 창 디자인은 자체 제작한다. 실제 OS·프로그램의 로고와 디자인은 흉내 내지 않는다 `[제안]`
