## 1. 미션의 역할 `[제안]`

- **최종 미션 = 의뢰를 끝내는 길.** 누구나 도달할 수 있게 둔다(★1 보장 — 02-04 §1-4 "적용").
- **나머지 미션 = 더 잘하고 싶은 사람의 목표.** 두 종류로 나눠 별의 의미를 다르게 한다.
  - **탐색**: 일부러 다른 길로 대상을 보내야 얻는다 → "길을 더 많이 알아냈다"
  - **솜씨**: 조작을 아껴 써야 얻는다 → "더 깔끔하게 해냈다"
- 그래서 ★2는 "탐색이나 솜씨 중 하나", ★3은 "둘 다"가 된다.

## 2. 미션 종류 `[제안]`

| 종류 | 분류 | 완료 조건 | 판정 시점 | 추적도 감소 | 챕터 |
| --- | --- | --- | --- | --- | --- |
| 출구 도달 | 최종 | 대상이 출구 위치를 지남 | 즉시 | 없음(의뢰 끝) | 0~ `[구현]` |
| 단말 통과(데이터 회수) | 탐색 | 대상이 단말 위치를 지남 | 즉시 | 있음 `[구현]` | 0~ `[구현]` |
| 층 방문 | 탐색 | 대상이 지정한 층(또는 섹터)에 들어감 | 즉시 | 있음 | 1~ |
| 추적도 제한 | 솜씨 | 의뢰가 끝날 때까지 추적도가 기준(예: 60) 이하를 유지 | 기준을 넘는 순간 실패 확정, 끝나면 완료 | 없음 | 1~ |
| 카운트다운 없이 | 솜씨 | 카운트다운에 한 번도 들어가지 않음 | 들어가는 순간 실패 확정 | 없음 | 2~ |
| 조작 횟수 제한 | 솜씨 | Shift를 누른 횟수가 기준(예: 4회) 이하 | 기준을 넘는 순간 실패 확정 | 없음 | 1~ |
| 시간 제한 | 솜씨 | 기준 시간(예: 90초) 안에 최종 미션 완료 | 시간이 지나면 실패 확정 | 없음 | 1~ |
| 감시 회피 | 솜씨 | 감시 카메라 시야 안의 섹터에서 Shift를 한 번도 쓰지 않음 | 쓰는 순간 실패 확정 | 없음 | 2~ |

- **탐색 미션만 추적도를 줄인다.** 솜씨 미션은 의뢰 끝에 판정되므로 중간 회복 수단이 되지 않는다(D-021의 "미션 달성으로 감소"를 탐색 미션에 한정 — 확정 필요).
- 솜씨 미션은 **실패가 확정되는 순간** MISSION 탭에 빨간 X로 표시한다. 실패해도 의뢰는 계속된다.
- 수치(기준값)는 의뢰마다 정하고 03-02 밸런스에서 조정한다.

## 3. 의뢰당 조합 규칙 `[제안]`

| 항목 | 규칙 |
| --- | --- |
| 미션 수 | **최종 1 + 나머지 2**(1차 범위 고정). ★2 = 나머지 1개, ★3 = 2개 |
| 조합 | 챕터 0: 탐색 2(튜토리얼 — 길만 익힘). 챕터 1부터: **탐색 1 + 솜씨 1** |
| 탐색 미션 위치 | 그 챕터의 새 요소를 써야 갈 수 있는 곳 |
| 솜씨 미션 고르기 | 그 의뢰에서 가장 "아끼고 싶은 것"(추적도·횟수·시간)과 맞춘다 |
| 서로 부딪힘 | 탐색 경로로 가면 솜씨 조건이 빠듯해지게 둔다 → ★3은 두 목표 사이의 줄타기 |
| 브리핑 | 미션 3개를 브리핑과 MISSION 탭에 모두 처음부터 보여 준다(숨은 미션 없음) |

## 4. 챕터별 미션 구성 `[제안]`

| 의뢰 | 최종 | 나머지 1 | 나머지 2 | ★3의 줄타기 |
| --- | --- | --- | --- | --- |
| 0-1 | 출구 | 단말 A(길 위) | 단말 B(길 위) | 없음(튜토리얼, 기본 ★3) `[구현]` |
| 0-2 | 출구 | 단말 A(길 위) | 단말 B(계단 너머) | 되돌아가는 시간·Shift 1회 더 `[구현]` |
| 1-1 | 출구 | 탐색: 발판 건너편 단말 | 솜씨: 추적도 60 이하 | 단말에 가려면 발판을 오래 붙잡아야 함 |
| 1-2 | 출구 | 탐색: 리프트로 3층 방문 | 솜씨: Shift 5회 이하 | 리프트·컨테이너·문을 적은 횟수로 묶어 처리 |
| 2-1 | 출구 | 탐색: 원격 문 너머 단말 | 솜씨: 감시 회피 | 카메라를 원격으로 돌려 둔 뒤 조작 |
| 2-2 | 출구 | 탐색: 경보 패널 뒤 단말 | 솜씨: 카운트다운 없이 | 추적도 예산 안에서 원격·조준 동시 처리 |

## 5. 화면 표시 `[제안]`

| 상태 | MISSION 탭 표시 |
| --- | --- |
| 진행 중(탐색) | 빈 체크 상자 + 이름 |
| 진행 중(솜씨) | 빈 체크 상자 + 이름 + 현재 값(예: `TRACE <= 60  (42)`, `SHIFT x5  (3)`) |
| 완료 | 체크 + 흐린 글자 |
| 실패 확정 | 빨간 X + 흐린 글자 |
| 결과 창 | 미션 3개 각각 완료/실패 표시 + 별 |

## 6. 데이터 형식 `[제안]`

미션 하나 = { 종류, 표시 이름, 대상(오브젝트·섹터·층), 기준값, 탐색 여부 }. 현재 구현의 "최종 + 단말 A·B 고정" 구조를 이 목록 형식으로 바꾼다(구현 지시서에서).

## 7. 정할 것

1. 나머지 미션을 **탐색/솜씨**로 나누는 구조와 ★ 의미(§1)
2. 미션 종류 목록(§2) — 넣을 것·뺄 것
3. 추적도 감소를 탐색 미션에만 적용(§2, D-021 해석)
4. 조합 규칙(§3): 의뢰당 최종 1 + 나머지 2, 챕터 1부터 탐색 1 + 솜씨 1
5. 챕터별 구성(§4)과 화면 표시(§5)
