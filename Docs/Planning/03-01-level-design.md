## 1. 챕터 0 — 튜토리얼: 주인공 건물 침입자 저지 (D-062, D-069, D-070)

> **2026-11-18 개편(v0.4.0)**: 챕터 0 컨셉이 사용자 결정으로 바뀌었다. 아래 §1-A가 정본이고, §1(구) SANDBOX 안(0-1·0-2, W-005로 구현됨)은 **대체 예정**이다.

### 1-A. 확정된 컨셉

- **주인공(해커)이 사는 건물에 도둑이 침입한다.** 플레이어는 **그 인물이 주인공이 있는 곳까지 도달하는 것을 막는다** — 이것이 튜토리얼이다 — D-069
- 챕터 0이 끝나면 **그 인물은 조력자가 되고**, 이후 챕터에서 **화면 안에서 활동하는 인물**(지금의 "의뢰 대상" 자리)이 된다 — D-070

### 1-B. 규칙에 주는 영향 `[제안]`

| 항목 | 챕터 0(침입자 저지) | 챕터 1~(조력자 안내) |
| --- | --- | --- |
| 화면 속 인물 | 침입자(같은 인물) | 조력자(같은 인물) |
| 플레이어 목표 | 인물이 **주인공 방에 닿지 못하게** 하고, **함정 방으로 유도해 가둠** | 인물을 **출구까지 보냄** |
| 장치의 현실 상태 | 인물에게 **유리**(문 열림, 계단 열림 등) → Shift로 **막거나 돌린다** | 인물에게 불리(문 닫힘 등) → Shift로 **연다** |
| 최종 미션 | 인물이 **함정 방**에 들어감(D-027: 최종 미션 완료 순간 의뢰 끝) | 출구 도달 |
| 실패 | 인물이 **주인공 방**에 닿음 → 그 자리에서 바로 다시 시작(튜토리얼이라 벌점 없음) | 추적도 카운트다운 → 게임오버(D-025) |
| 나머지 미션 | 예: "인물이 2층에 한 번도 오르지 않게"(솜씨), "로비 보안 단말 앞을 지나가게 해 얼굴 기록"(탐색) | 02-05 |

- 새 기능은 **실패 지점(주인공 방)** 하나다. 대상 이동·장치 규칙은 그대로 쓰고, 장치의 현실/설계도 상태만 뒤집어 배치한다.
- 같은 조작(조준·Shift)을 "막는 쪽"으로 먼저 배우고, 챕터 1에서 "여는 쪽"으로 쓰게 되어 **같은 동사를 반대 목적으로 다시 배우는 흐름**이 생긴다.

### 1-C. 의뢰 구성 `[제안]`

| 의뢰 | 맵 | 가르치는 것 | 흐름 |
| --- | --- | --- | --- |
| 0-1 | 주인공 건물 1~2층(2층 끝 = 주인공 방), 1층 끝 창고 = 함정 | 조준 점프, Shift는 누르는 동안만 | 침입자가 계단을 오르려는 순간 계단 셔터를 **닫아**(Shift) 보내지 않음 → 1층 끝까지 간 침입자 앞에서 창고 문을 **열어**(조준 점프 후 Shift) 들어가게 함 → 가둠 |
| 0-2 | 주인공 건물 1~3층(3층 = 주인공 방), 엘리베이터, 2층 복도 레이저 | 섹터 전체(레이저), 엘리베이터, 추적도와 중계기 | 엘리베이터를 **멈춰** 3층행을 막음 → 2층 복도 레이저를 **켜서**(섹터 전체) 막음 → 지하 보일러실로 가는 엘리베이터를 작동시켜 가둠 |

- 끝 장면(0-2 종료 대화): 갇힌 인물과 문자 메시지로 대화 → 조력자가 되는 계기. 대사·이름·이유는 시나리오 단계에서 정한다.
