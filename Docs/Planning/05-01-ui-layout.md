## 1. 화면 배치

기준 해상도 640×360 `[제안]`(아트 파이프라인 D-039). 전체가 가상 프로그램 창 하나다(D-008).

```
┌─ 프로그램 창 제목줄 ─────────────────────────────────────┐
│ ┌──────────── 현실 장면(격자) ────────────┐ ┌[미션][대화]┐ │
│ │                                         │ │ 미션 목록    │ │
│ │   조준틀 · 의뢰 대상 · 칸               │ │  또는       │ │
│ │                                         │ │ 대화 기록    │ │
│ │                                         │ ├─────────────┤ │
│ │                                         │ │ 캐릭터 얼굴  │ │
│ └─────────────────────────────────────────┘ │ (초상)      │ │
│ [추적도 게이지 ■■■■□□]   > 명령 기록 줄      └─────────────┘ │
└──────────────────────────────────────────────────────────┘
```

| 영역 | 내용 | 근거 |
| --- | --- | --- |
| 오른쪽 위 패널 | **미션과 대화가 같은 패널을 쓴다.** 상단에 **카테고리 전환 버튼 [미션] [대화]**, 버튼 아이콘 오른쪽 아래에 `]` 표시 | D-043, D-044, D-050, D-051 |
| 오른쪽 아래 패널 | **캐릭터 얼굴(초상) 출력 화면** | D-042 |
| 왼쪽 큰 영역 | 현실 장면 격자 | 기존 |
| 아래 줄 | 추적도 게이지, 명령 기록 줄 | 위치는 `[제안]` |

## 2. 카테고리 전환

- 패널 상단 버튼으로 [미션] ↔ [대화]를 바꾼다 — D-044
- 마우스를 쓰지 않으므로(D-036) 키로 전환한다. 전환 키는 **`]`** — D-050 (D-044의 '영문 키' 부분을 대체)
- `]`는 시스템 조작키로 다룬다(D-006 시스템 키 예외). 키 판정은 물리 키 위치(US 배열의 `]` 자리)로 한다 `[제안]`. 비 US 배열에서는 같은 자리의 다른 글자가 찍힌 키다 → 화면 표시로 안내(T-006)

### 2-1. 시스템 조작키 표시 — D-051

- 시스템 조작키(`]`, `ESC`, `Enter` 등)는 **인게임 화면에 노출**한다.
- 크기는 **사람이 알아볼 수 있는 범위에서 최소**로 출력한다. `[제안]` 키 표시 배지 **높이 11px**(640×360 기준: 테두리 1 + 여백 1 + 5×7 글자 + 여백 1 + 테두리 1), 어두운 바탕 + 흰 글자. 9px 시안은 글자가 테두리에 붙어 읽히지 않아 올렸다
- 위치는 해당 **시스템 버튼 아이콘의 오른쪽 아래**. 예: 카테고리 전환 버튼 아이콘 오른쪽 아래에 `]`, 일시정지 아이콘 오른쪽 아래에 `ESC`

## 3. 대화

- 캐릭터 간 대화는 **의뢰 시작(브리핑)과 종료(결과) 때만** 나온다. 플레이 중에는 대화가 없다 — D-045
- [대화] 탭은 **문자 메시지 형식** UI로 디자인한다 — D-046
  - 형식 `[제안]`: 메신저처럼 위에서 아래로 쌓이는 말풍선. 상대(의뢰인 등)는 왼쪽, 해커 본인은 오른쪽. 말풍선 위에 보낸 사람 이름과 시각
  - 해커가 원격으로 의뢰를 주고받는 설정(D-008, D-014)과 맞음
  - 도트 스타일(D-035)로 말풍선 테두리·꼬리를 그린다 `[제안]`
- 대화가 나오는 동안 패널은 [대화] 탭, 오른쪽 아래에는 말하는 캐릭터의 얼굴 `[제안]`
- 대사 넘기기: `Enter` `[제안]`(시스템 조작 D-037과 같은 키)
- 플레이 중 [대화] 탭은 브리핑 대화 기록을 다시 보는 용도 `[제안]`
- 얼굴 패널의 초상은 **96×96 도트** — D-049. **MVP 단계에서는 주인공(해커) 초상만** 만든다 — D-047. 의뢰인 등 상대의 말풍선은 이름만 표시 `[제안]`
- 추적도에 따라 표정이 바뀌는 연출은 검토 항목

## 4. UI 아트 시안

- 레시피 `Art/recipes/ui_mvp.py`, 부품 PNG는 `Art/Export/ui/`, 목업은 `Art/Export/preview/ui_mockup_mission_x2.png`, `ui_mockup_log_x2.png`
- 부품: 창 틀(제목줄 20px), 패널, 탭(활성·비활성), 말풍선(상대 왼쪽 회색·해커 오른쪽 파랑), 버튼(보통·선택), 추적도 게이지, 체크 상자, 별, 일시정지·탭 전환 아이콘, 키 배지(`ESC`·`]`·`ENTER`), 5×7 도트 글꼴 아틀라스
- 늘어나는 부품은 9-slice 테두리 값을 `Art/Export/manifest.json`에 적었다
- 모두 `[제안]` 시안이다
