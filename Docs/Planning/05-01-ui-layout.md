## 1. 화면 배치

기준 해상도 640×360 `[제안]`(아트 파이프라인 D-039). 전체가 가상 프로그램 창 하나다(D-008).

```
┌─ 프로그램 창 제목줄 ─────────────────────────────────────┐
│ ┌──────────── 현실 장면(격자) ────────────┐ ┌[미션][대화]┐ │
│ │                                         │ │ 미션 목록    │ │
│ │   조준틀 · 의뢰 대상 · 칸               │ │  또는       │ │
│ │                                         │ │ 대화 기록    │ │
│ │                                         │ ├─────────────┤ │
│ │                                         │ │ 캐릭터 얼굴  │ │
│ └─────────────────────────────────────────┘ │ (초상)      │ │
│ [추적도 게이지 ■■■■□□]   > 명령 기록 줄      └─────────────┘ │
└──────────────────────────────────────────────────────────┘
```

| 영역 | 내용 | 근거 |
| --- | --- | --- |
| 오른쪽 위 패널 | **미션과 대화가 같은 패널을 쓴다.** 상단에 **카테고리 전환 버튼 [미션] [대화]** | D-043, D-044 |
| 오른쪽 아래 패널 | **캐릭터 얼굴(초상) 출력 화면** | D-042 |
| 왼쪽 큰 영역 | 현실 장면 격자 | 기존 |
| 아래 줄 | 추적도 게이지, 명령 기록 줄 | 위치는 `[제안]` |

## 2. 카테고리 전환

- 패널 상단 버튼으로 [미션] ↔ [대화]를 바꾼다 — D-044
- 마우스를 쓰지 않으므로(D-036) **Shift 없이 누르는 영문 키 하나**로 전환한다. 플레이 중 쓸 일이 적은 키를 고른다 — D-044
- 키 후보 `[제안]`: **`Q`**. 왼손이 왼쪽 Shift 근처에 있어 누르기 쉽고, 다른 조작에 쓸 일이 적다. 레벨 기획에서 `Shift + 영문` 이름표 조합(D-032)을 정할 때 `Q`는 이름표 글자에서 뺀다
- 버튼에는 키 표시를 붙인다. 예: `[Q] MISSION | LOG`

## 3. 대화

- 캐릭터 간 대화는 **의뢰 시작(브리핑)과 종료(결과) 때만** 나온다. 플레이 중에는 대화가 없다 — D-045
- [대화] 탭은 **문자 메시지 형식** UI로 디자인한다 — D-046
  - 형식 `[제안]`: 메신저처럼 위에서 아래로 쌓이는 말풍선. 상대(의뢰인 등)는 왼쪽, 해커 본인은 오른쪽. 말풍선 위에 보낸 사람 이름과 시각
  - 해커가 원격으로 의뢰를 주고받는 설정(D-008, D-014)과 맞음
  - 도트 스타일(D-035)로 말풍선 테두리·꼬리를 그린다 `[제안]`
- 대화가 나오는 동안 패널은 [대화] 탭, 오른쪽 아래에는 말하는 캐릭터의 얼굴 `[제안]`
- 대사 넘기기: `Enter` `[제안]`(시스템 조작 D-037과 같은 키)
- 플레이 중 [대화] 탭은 브리핑 대화 기록을 다시 보는 용도 `[제안]`
- 플레이 중 오른쪽 아래 얼굴 패널에는 의뢰인 또는 해커 본인의 얼굴을 띄운다 `[제안]`. 추적도에 따라 표정이 바뀌는 연출은 검토 항목

## 4. 미정

- 등장 캐릭터(해커 본인, 의뢰인 등)와 초상 크기 — 초상은 타일보다 큰 도트(예: 64×64 또는 96×96) `[제안]`
- 추적도 게이지·명령 기록 줄의 최종 위치
- 대화 문장 내용(시나리오)
