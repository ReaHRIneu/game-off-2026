## 1. 범위

- 게임을 실행하면 **메인 화면**과 **스테이지(의뢰) 선택 화면**을 거쳐 스테이지로 들어간다. 이 흐름을 만들고 연결한다 — D-055
- MVP-1 범위(D-034)에서 제외했던 "의뢰 선택 화면"을 이번에 추가한다(D-055가 범위를 넓힘)
- v0.1.0의 "도시 배경 + 로고 메인", "의뢰 게시판" 제안은 사용자 결정 D-056~D-059로 대체했다

## 2. 화면 흐름 — D-056~D-059

```
[부팅] → [메인: 방 일러스트] ─게임 시작(Enter)→ [모니터 켜짐 → 로딩] → [컴퓨터 바탕화면]
                                                                      │ 의뢰 아이콘 선택(Enter)
                                                                      ↓
                                     [게임] ← [로딩] ←(Enter 한 번 더)─ [오른쪽에 상세 패널 등장]
                                       │ 결과 Enter                         │ ESC: 패널 닫기
                                       └────────→ [컴퓨터 바탕화면] ←────────┘
바탕화면에서 ESC → 메인(모니터 꺼짐)   메인 CREDITS → 크레딧 ─ESC→ 메인
의뢰 중 ESC → 일시정지 [계속 / 다시 시작 / 바탕화면으로]
```

| 단계 | 내용 | 근거 |
| --- | --- | --- |
| 메인 | 주인공이 **방 안에서 컴퓨터 책상 앞 의자에 앉아 있는 일러스트**. 메뉴: 게임 시작, 크레딧 | D-056 |
| 게임 시작 | '게임 시작'을 실행하면 **컴퓨터(모니터)에 불이 켜지고 로딩**이 진행된 뒤 **컴퓨터 바탕화면**으로 전환 | D-057 |
| 바탕화면 | **컴퓨터 바탕화면에서 스테이지(의뢰)를 선택** | D-058 |
| 상세 패널 | 의뢰 하나를 선택하면 **화면 오른쪽에 상세 정보 패널이 등장**. **트리거를 한 번 더** 작동하면 **로딩 후 게임으로 전환** | D-059 |

- 조작: 방향키로 고르고 Enter로 결정, ESC는 뒤로·일시정지 — D-036, D-037. 화면마다 시스템 키 표시 — D-051
- "트리거"는 Enter로 해석한다(D-037 결정 키) `[제안]`
- 브리핑·결과 대화(D-045)는 게임 화면 안의 단계로, 대화 시스템은 W-003에서 구현한다

## 3. 메인 화면 `[제안]`

- 시점: 주인공의 **뒤쪽 비스듬한 시점**(등과 뒷머리·헤드셋이 보이고 모니터가 정면). 얼굴은 대화 초상에서 보여 준다
- 방: 어두운 방, 오른쪽 창밖으로 도시 야경(배경 레이어 재사용), 책상 위 키보드·에너지 음료 캔·케이블. **마우스는 책상에 없다**(마우스를 쓰지 않는 게임 — D-036)
- 메뉴(START, CREDITS)와 로고(임시 표기)는 화면 왼쪽 위
- 모니터 꺼짐 / 켜짐 두 상태. 켜지면 모니터 빛이 주인공과 책상을 비춘다

## 4. 로딩과 바탕화면 `[제안]`

- 게임 시작 로딩: 모니터 화면 안에 부팅 글자가 올라가고 진행 막대가 찬 뒤, 모니터 화면이 전체 화면으로 바뀐다(바탕화면)
- 바탕화면: 자체 디자인의 가상 OS(실제 OS 모방 금지). 청사진 격자 배경화면, 의뢰 파일 아이콘(`REQ_01` 등, 잠김·완료·별 표시), 아래 작업 표시줄(키 안내·시계)
- 상세 패널: 오른쪽에서 나타나는 창. 의뢰 제목·의뢰인·요약·미션·최고 별·`CONNECT` 버튼(`ENTER` 배지)
- 게임 진입 로딩: `CONNECTING TO CAM 03...` 진행 막대
- 잠긴 의뢰 아이콘은 선택은 되지만 상세 패널에 `LOCKED`만 표시, 진입 불가
- 의뢰 #02~#04는 레벨 기획 전이라 잠긴 아이콘으로 둔다(D-032)

## 5. 진행 저장 `[제안]`

- 의뢰별 최고 별과 잠금 해제 상태만 저장한다(Unity PlayerPrefs — Web에서는 브라우저 저장소)
- 저장이 실패해도 게임은 진행된다(그 세션 동안만 유지)
- 개인 정보는 저장하지 않는다
