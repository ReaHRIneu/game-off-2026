# game-off-2026

A puzzle game made for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026) (theme: **SHIFT**). Work in progress — title not decided yet.

- **Concept (WIP):** You are an underground hacker in a sci-fi dystopia. Through a fictional program window you watch real-world scenes and take on jobs and solve them remotely. Hold **Shift** to distort the targeted space and bend reality. Controls are keyboard shortcuts: Shift alone at first, then Shift + arrows / letters / numbers.
- **Engine:** Unity 6 (Universal 2D), Web build on itch.io
- **Team:** solo

## 한국어 요약

GitHub Game Off 2026 참가작(주제 SHIFT)입니다. 플레이어는 SF 디스토피아의 뒷세계 해커이며, 가상의 프로그램 창 속 현실 장면을 보며 원격으로 의뢰를 수행합니다. Shift를 누르는 동안 조준한 공간이 왜곡되고, 이를 이용해 현실을 조작합니다.
